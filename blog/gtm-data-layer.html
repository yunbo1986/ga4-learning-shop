How the dataLayer Connects Your Site to GTM

The dataLayer is a clean message board between the website and your analytics tags.

The website describes what happened

When a visitor performs an important action, the site pushes a structured message into dataLayer. That message contains an event name and the details GTM may need.

Simple flow: visitor clicks → website pushes an event → GTM trigger listens → variables read the details → GA4 tag sends the event.

Triggers listen for event names

A Custom Event trigger can listen for a name such as generate_lead. It only activates the matching tag when that exact message enters the dataLayer.

Variables carry the details

Data Layer Variables read values such as currency, order value, transaction ID, or article title. The tag then maps those values to GA4 event parameters.

Preview before publishing

GTM Preview lets you select an event and confirm which tags fired, which did not fire, and what every variable contained. This is the safest place to find naming or configuration mistakes.
